# Design

[Project index](../README.md)

libfmp is a Rust-first SDK for the FMP HTTP API. Its value is the endpoint
contract, not computation: every call is one HTTPS GET, one JSON decode, and
one structured error path. The project keeps that contract in one place and
ships it to three languages.

## One contract, three decoders

- **Rust core** (`crates/libfmp`): transport-independent endpoint descriptors, typed queries, response models, and the 271 `Client` methods. The Rust source is the reference for every name, argument kind, and response shape.
- **Python** (`crates/fmp-py`): a pyo3 extension over the Rust client. The namespaces, models, stubs, and public packages are generated from the registry under `crates/fmp-py-gen/registry/` and the Rust signatures, so the Python surface cannot drift from the Rust one.
- **Go** (`sdk/go`): a pure Go client, generated by `gen_go` from the same registry and the Rust response models. It mirrors the Rust crate one-for-one: client options, authentication modes, error categories, and transport rules, with no cgo and no native library.

The registry is validated against the real `libfmp` signatures before any
generator runs (`registry_check`), and the generated files carry a
`DO NOT EDIT` header.

## Shared fixtures as the parity oracle

The recorded wire fixtures under
[`crates/libfmp/tests/fixtures`](../crates/libfmp/tests/fixtures/README.md)
are the parity oracle. The Rust suites decode them, the Python suite reads
them through `conftest.load_fixture`, and every fixture decodes through the
Go models, so the three decoders are proven against the same bytes. No test
in those suites opens a network connection; live tests are a separate,
opt-in set.

## Transport rules

Endpoint code describes only the HTTP method, relative path, typed query, and
response shape. Base URLs, path prefixes, authentication, default headers,
redirects, and timeouts are client-configuration concerns, so switching
between direct FMP access and a proxy never touches endpoint code. Two rules
hold in every language:

- **Never retry.** Rate limits, entitlement errors, and server errors all surface as one structured status error; the caller decides what to do next.
- **Redact credentials.** Secret values never appear in error rendering, logging, or formatted client and authentication values, and redirect following is either disabled or restricted to the same origin so a credential is never forwarded across origins.

## Decision records

- [ADR index](../docs/adr/): one record per domain's API names and contracts, starting with the [v0.1 public architecture](../docs/adr/0001-v0.1-public-architecture.md).
- [ADR 0030](../docs/adr/0030-go-sdk-architecture.md): the Go SDK architecture, including why it is generated rather than bound through cgo.
- [ADR 0031](../docs/adr/0031-pre-1.0-contract-decisions.md): pre-1.0 contract decisions (error equality without a source chain, `#[non_exhaustive]` responses, `f64` quantities, exact numeric strings, Python model equality, the `fmp` import name).
- [ADR 0032](../docs/adr/0032-naming-policy.md): the naming policy for methods, row types, and Go initialisms across all three SDKs.
- [ADR 0033](../docs/adr/0033-nullable-response-members.md): nullable response members, and `""` or null on typed codes and dates decoding to `None` / `nil`, from observed wire evidence.
- [Contract ambiguities register](../docs/contract-ambiguities.md): where the captured documentation is silent or contradictory, the SDK keeps an explicit raw type, a closed query, or a strict decode rather than a guessed schema. The register lists those deferred decisions.
